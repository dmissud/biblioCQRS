# Objets métier : prets

## Objets

- Emprunt (Loan) : acte de prêter un exemplaire physique à un adhérent pour une durée déterminée (document : SRC-002, 2. Modèle du Domaine (Glossaire)) [hypothèse]
- L'enregistrement d'un emprunt se fait à partir de l'ID de l'exemplaire et de l'ID de l'adhérent (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]
- L'emprunt enregistré porte une date de retour maximale (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]

## Cycle de vie

- Un emprunt peut être en cours (actif) (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]
- Un statut « en retard » existe pour un emprunt (document : SRC-004, 4.1 Incohérences / Points à creuser, point 1) [hypothèse]

## Questions ouvertes

- Quelle est la fin de vie d'un emprunt (retour, perte, dégradation) ? Rien n'est décrit ; l'atelier « Retour et Litiges » est prévu (vu dans SRC-004, 4.2 Ateliers prévus)
- Le statut de l'exemplaire (« emprunté ») est-il porté par l'exemplaire ou déduit des emprunts ? (vu dans SRC-004, 4.1 Incohérences / Points à creuser)
