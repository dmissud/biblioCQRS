# UC-PRETS-01 : Enregistrer un emprunt

## Comportement actuel

- L'usager, adhérent, a un livre dans les mains et souhaite l'emprunter (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]
- Le documentaliste enregistre l'emprunt dans le système en fournissant l'ID de l'exemplaire et l'ID de l'adhérent (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]
- Le système vérifie les règles d'emprunt (voir rules.md) (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]
- Le système enregistre l'emprunt, fixe la date de retour maximale et en informe le documentaliste (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]
- Le documentaliste informe l'usager de sa date de retour maximale (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]
- Si une règle n'est pas respectée, le système refuse l'emprunt (document : SRC-003, 3.4 Scénarios : Emprunt d'un exemplaire) [hypothèse]
